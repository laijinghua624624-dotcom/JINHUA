一、系统概览

Lance智能裤是为内容策划总监量身定制的个人创作工作系统，核心定位是造势型预热视频选题库，帮助你快速完成从创意灵感→选题策划→脚本分镜→项目管理的全流程工作。

🎯

双项目模式

TMD（辛选）+ My（个人项目），数据隔离，一键切换

📚

选题库

8种造势类型分类，支持版本管理、核心方向锁定

🎬

分镜脚本

25镜模板，支持拍照/拍视频/上传参考图

🎨

审美参考库

14种类型，60+标签，全局共用，AI视频生成

🏗️

舞美舞台库

体育馆/摄影棚/户外，电影节/秀场/音乐会类型

🤖

AI智能体团队

想法策划/参考搜索/库管助手，支持附件上传

💡

灵感速记

录音捕捉灵感，AI整理成创意模型库

📊

专场策划案

大项目管理，完成度提醒，内容规划表

二、快速上手（5分钟）

1

打开系统

在浏览器中打开 https://laijinghua624624-dotcom.github.io/JINHUA/，或直接打开本地 index.html 文件。系统支持 iPhone、iPad、Mac 多平台自适应。

2

切换项目模式

点击顶部左上角的项目切换器（默认显示"TMD"），可以在 TMD（辛选） 和 My（个人项目） 之间切换。两个模式的数据完全隔离，审美参考库全局共用。

3

创建第一个选题

点击左下角的 + 新建选题 按钮，填写选题标题、类型、核心创意描述。系统预置了8种造势类型：重磅官宣型、倒计时系列、悬念预告型、气场大片型、战绩回顾型、筹备幕后型、机制炸场型、联名嘉宾型。

4

完善分镜脚本

在选题详情页点击 分镜脚本 按钮，打开分镜编辑器。系统预置25镜模板，你可以逐镜填写景别、运镜、时长、画面描述、台词旁白。点击每个镜头的参考图区域，可以拍照/拍视频/上传文件作为参考。

5

使用AI助手

点击右上角 AI助手 按钮，打开AI智能体团队。你可以：① 把零散想法发给"想法策划"生成结构化选题；② 上传参考图片/视频给AI分析；③ 让"库管助手"整理你的选题库。

💡 小贴士：系统数据默认保存在浏览器本地（localStorage），清除浏览器数据会丢失。建议定期使用"导出"功能备份数据，或配置云端同步（Supabase）实现多设备自动同步。

三、TMD（辛选）板块详解

TMD模式是为辛选团初瑞雪直播账号量身定制的工作模式，聚焦造势型预热视频的全流程管理。

3.1 左侧导航功能

📋

选题库

核心功能，管理所有预热视频选题，支持筛选、搜索、排序

💡

灵感速记

录音捕捉灵感，AI整理成结构化创意，一键转为选题

📅

专场排期

按直播专场管理预热视频排期，支持策划案和完成度提醒

📊

数据看板

选题状态统计、类型分布、专场进度可视化

🎨

审美参考库

收藏视觉参考，14种类型，支持AI视频生成（全局共用）

🏗️

舞美舞台库

舞台设计方案管理，场地类型+舞台类型双维度筛选

⭐

辛选专属

品牌档案、账号画像、历史预热库、视觉规范、内部资源

3.2 选题状态流转

每个选题有4种状态，帮助你跟踪进度：

→

待拍

创意已确认，等待拍摄执行

→

已拍

拍摄完成，进入后期制作

→

已发

视频已发布，可复盘数据

→

搁置

暂时不执行，保留创意

3.3 版本管理系统

每个选题支持多版本管理，适合"慢下来细化修改"的工作方式：

  • 核心方向锁定：锁定主题、调性、叙事结构、核心画面，防止修改跑偏
  • 版本时间线：可视化展示所有版本，当前版本高亮
  • 版本对比：并排显示两个版本的差异，修改处红色标注
  • 回退版本：创建新版本回退到历史版本，旧版本保留不删除

四、My（个人项目）板块详解

My模式是你的个人创作工作室，以导演/摄影师身份管理商业广告、纪录片、电影创作等个人项目。

4.1 个人身份横幅

进入My模式后，顶部会显示你的个人创作档案：

  • 创作履历：入行年份、坐标、片中职务、作品数量

五、核心功能使用指南

5.1 分镜脚本编辑器

分镜编辑器是系统的核心功能之一，支持完整的镜头脚本管理：

1

打开分镜编辑器

在选题详情页点击底部的 分镜脚本 按钮，或在选题卡片上点击"分镜"图标。

2

填写镜头信息

每个镜头包含：镜号、景别（远景/全景/中景/近景/特写/大特写）、运镜（固定/推/拉/摇/移/跟/升降/旋转/手持）、时长、画面描述、台词旁白、备注。

3

添加参考图

点击每个镜头的参考图区域，有3种方式：📷拍照（直接调用摄像头）、🎥拍视频（录制视频参考）、📎上传（从相册选择）。手机上特别方便，看到好的构图直接拍照保存。

4

画面比例策略

系统采用 4:3 Open Gate 拍摄母版，9:16竖屏为主输出（快手/抖音/视频号），16:9横屏为保底（B站/西瓜/微博）。在分镜中可以标注每个镜头的构图重点。

5.2 审美参考库

审美参考库是你个人的审美积累平台，支持14种类型：

舞台设计 / 声光电 / 灯光设计 / 音效参考 / 真实照片 / AI生成 / CG视觉 / 电影截图 / 广告TVC / 秀场参考 / 音乐会现场 / 运镜参考 / 调色参考

→

添加参考

点击"添加参考"按钮，上传图片（自动压缩）或粘贴视频链接，填写标题、类型、标签、描述。

→

AI视频生成

点击"AI生成视频"按钮，输入画面描述，调用即梦API生成5-10秒视频，自动保存到审美参考库。运行本地代理前，需先设置 VOLC_ACCESS_KEY_ID 和 VOLC_SECRET_ACCESS_KEY 环境变量。

5.3 专场策划案

对于大型直播专场（如双十一），可以创建专场策划案进行整体管理：

  • 内容规划表：默认预热视频4条 / 福利视频10条 / 直播流程1条 / 幕后花絮3条
  • 完成度进度条：实时显示项目整体完成度
  • 待办提醒：催促你往前推进，不会遗漏关键节点
  • 关联选题：把选题库中的选题关联到专场，统一管理

5.4 灵感速记 + 创意模型库

你有随时录音捕捉灵感的习惯，系统为你定制了灵感速记功能：

1

录音捕捉

点击灵感速记页面的录音按钮，直接录制你的想法。支持手机和电脑，录制完成后自动保存。

2

AI整理结构化

点击"AI整理"按钮，系统会从混乱的录音中提取：主题、核心画面、调性关键词、叙事结构、创意要点、标签。

3

创意模型库

整理后的灵感会进入创意模型库，系统会统计高频标签、生成AI创意建议。随着使用越多，系统越了解你的创作偏好。

4

一键转为选题

在灵感详情页点击"转为选题"，直接把灵感创建为正式选题，进入选题库管理。

六、AI智能体团队使用

系统内置3个AI智能体，各司其职，帮助你提升工作效率：

💡

想法策划

把你脑子里的零散想法、录音转文字内容发过来，帮你整理成结构化选题+完整可执行脚本。

🔍

参考搜索

根据你的创意方向，搜索全网类似案例、视觉参考、音乐参考，帮你拓宽创意视野。

📦

库管助手

帮你管理选题库，自动分类、打标签、整理归档，提醒你待办事项和项目进度。

6.1 配置API

首次使用AI助手需要配置API：

1

打开设置

点击顶部右上角的设置图标（齿轮），打开API设置面板。

2

填写API信息

填写 API Base URL、API Key、模型/接入点ID。你有豆包API Key，直接填入即可。

3

配置即梦AI视频

先按API指南通过环境变量启动即梦本地代理，然后在"AI视频生成"部分填写代理地址（默认 http://localhost:8765）。

6.2 上传附件给AI

AI助手支持上传附件，让AI基于你的参考素材生成创意：

  • 图片：上传参考图，AI会分析画面风格、构图、色调
  • 视频：上传视频参考，AI会分析运镜、节奏、叙事结构
  • 文档：上传PDF/Word/TXT，AI会提取关键信息

点击输入框旁边的 📎 按钮，选择文件上传。附件会显示在输入框上方，可以删除。发送消息后，AI会自动结合附件内容和文字描述生成回复。

七、进阶技巧

7.1 项目制 vs 单条创意

系统支持两种创建模式：

  • 项目制：你负责整场直播的预热视频规划、创意、执行及落地。创建专场策划案，统一管理多条预热视频。
  • 单条创意补全：项目其他人在执行，你只负责出一条视频创意补全现有的项目。直接创建选题，关联到已有专场。

7.2 快速响应 vs 慢下来细化

系统同时支持两种工作节奏：

  • 快速响应：有创意马上录入选题库，用AI助手快速生成脚本大纲，随时可以跟初瑞雪汇报。
  • 慢下来细化：使用版本管理系统，锁定核心方向，逐版本细化修改。每个版本都有修改说明，可以对比差异，可以回退。

7.3 多设备同步

系统支持3种数据同步方式：

1

本地模式（默认）

数据保存在浏览器本地，无需网络，速度最快。但清除浏览器数据会丢失，多设备不同步。

2

导出/导入备份

点击"导出"按钮，把当前项目数据导出为JSON文件。备份不包含API密钥；在另一台设备上导入后，需重新填写密钥。

3

云端同步（Supabase）

在设置中配置你自己的Supabase项目URL和publishable key，并先为 app_data 表设置RLS策略。不要在前端填写service_role secret key。启用后，选题等数据按项目隔离同步，审美参考库仍在所有项目之间共用。

八、常见问题

Q1：数据会丢失吗？

A：默认数据保存在浏览器本地（localStorage），只要不清除浏览器数据就不会丢失。建议定期使用"导出"功能备份，或配置Supabase云端同步。

Q2：AI助手用不了怎么办？

A：首先确认在设置中配置了正确的API Key和接入点。如果调用失败，检查网络连接，或配置代理地址。即梦AI视频生成需要本地运行代理脚本 python3 jimeng_proxy.py。

Q3：手机上怎么使用拍照功能？

A：在分镜编辑器中点击参考图区域的"📷拍照"按钮，手机会自动调用摄像头。拍照后可以选择重拍或使用，照片会自动保存为该镜头的参考图。

Q4：TMD和My模式的数据会混在一起吗？

A：不会。两个模式的选题库、灵感速记、舞美舞台库、专场策划案等数据完全隔离。只有审美参考库是全局共用的，因为审美是你个人的积累。

Q5：怎么把创意快速汇报给初瑞雪？

A：在选题详情页，系统已经按照你的汇报习惯组织了内容：创意大纲、创意描述、创意寓意、旁白台词、场景场地、美术制景参考、道具参考、影像氛围参考、摄影调性参考、配乐参考、25镜分镜脚本。可以直接截图或导出为PPT汇报。

Q6：系统可以自主学习吗？

A：当前版本是"数据飞轮"模式——你使用越多，录入的选题、灵感、参考越多，AI生成的建议就越符合你的风格。但这不是真正的自主学习，AI不会自动修改你的数据。建议先把三大库（选题库、审美参考库、舞美舞台库）数据攒到50条以上，再加智能推荐模块。
