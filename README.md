# Lance 内容工作台 · 单人创作系统

给 Lance 个人使用的内容策划、汇报与拍摄深化系统。唯一工作台入口是 `index.html`。代码同步到 GitHub 不等于服务上线：AI调用、媒体核验与视频合成仍需启动本机后端。

## 启动

需要 Python 3.10+ 和 FFmpeg（含 ffprobe）。PDF 文本提取建议安装 Poppler，扫描件 OCR 建议安装 Tesseract 与中文语言包；macOS 可执行 `brew install poppler tesseract tesseract-lang`。首次在项目目录安装依赖并启动：

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python studio_server.py
```

打开 http://127.0.0.1:8787 。该端口专用于 JINHUA；`8000` 留给其他项目，`8765` 留给旧版即梦代理。不能用普通静态服务器替代，也不要直接双击 HTML。默认只监听本机。前端依赖包已构建，可直接使用；修改 PPT 依赖后执行 `npm ci && npm run build`。当前服务已启动；本机登录自启动未通过验收，已撤回该配置。关机或进程退出后需重新运行，不能当作云服务器。

模型 ID 与 API Key 只在本机 `.env` 配置，前端弹窗不接收密钥：

```dotenv
ARK_API_KEY=填写新的方舟密钥
ARK_TEXT_MODEL=支持看图和JSON输出的模型或接入点ID
ARK_IMAGE_MODEL=支持多参考图及2304x1728输出的图片模型ID
ARK_VIDEO_MODEL=支持图生视频及8秒输出的视频模型ID
```

修改 `.env` 后重启服务。新版本采用方舟 Ark 文本、图片与视频接口；旧版即梦 AK/SK 代理仍保留，但新版不会自动使用它。模型权限、区域、参数和费用必须在你的账户实际验证。连接检查只确认本机服务，不代表付费模型可用。不承诺固定五分钟完成视频生成。

## 使用路线

1. 建单条脚本或专场，输入想法。专场片数按实际需求设置，不写死为6条；调整计划数不会删除已有脚本。
2. 快速汇报：完整创意字段、A/B/C 三套视频封面推荐、3–5 张真实参考图、开场／中间／结尾各 8 秒 AI 视频。每套封面包含实际竖版底图、可编辑主标题、辅助文案、构图与点击逻辑；系统标记首选并保存理由。缺项时允许预览，不允许导出“完整汇报”或确认方向。
3. PPT汇报提供三种导出。**老板决策版**先展示主推方向、依据、各条分工、首选封面、资源边界和拍板事项，页数随实际故事数调整。必须有大纲及寓意或推荐要点；素材不齐时标明“方向讨论稿”，列出完整交付缺项。**完整策划版**包含主汇报和全部强制内容附件，图片及三段8秒视频实际内嵌，缺项不能导出。**单条执行版**包含已确认的快速稿、12类执行方案、25镜AI图和完整AI成片。
4. 在“编辑汇报要点”填写主推、依据、已确认事实、待确认、备选、资源和决策项，也可点“AI提炼汇报要点”补充空字段（需配置文本模型）。AI不会填写“已确认事实”或覆盖手填内容。参考图和视频可填写“汇报借鉴要点”，随图显示。导出前可预览实际页序；长文自动分页，主汇报摘要的全文保存在备注及完整附件。下载文件名区分版本，同时保存至“成果与备份”，支持重新下载。视频为内嵌MP4，正式汇报前请在使用的PowerPoint/WPS设备上试播。
5. 审美参考 → 新建场景资料：上传尺寸图、现场图／视频、现有参考。填写已核对尺寸，未知项保留待确认。PDF 可归档，识图需上传清晰截图。原有场景记录、尺寸和分析保留。
6. 审美参考 → 新建服装资料：按分类上传历史视频，提取 12 个均匀采样候选帧，再由看图模型识别、推荐；选中造型供关联项目使用。这不是自动精确分割全片每套衣服。原有服装库存、分析和已选造型保留。
7. 视频反推：主流程收敛为“上传原片 → 提取12张关键帧 → 反推详细故事 → 预览/下载PDF”，不额外生成参考图、参考视频或封面。反推结果先说清创意来源、推导链、内容目标贴合度和3分钟汇报摘要，再展开起承转合、完整故事脚本、每张关键帧的故事作用、动作情绪、构图景别、运镜思考、剪辑思考、声音、衔接、证据边界和从故事到落地的执行路径。有音轨的原片可转写并人工核对；也可选补充已有文字或照片。采样画面不是完整切镜检测，无法从单帧确认的运镜和切点会明确标为待核对。
8. 审美参考：统一场景、服装和AI、摄影、美术、舞台声光电、分镜等参考入口。新建自定义文件夹，编辑名称、用途说明及素材归属；一份素材可归入多个文件夹，取消归属不会删除素材。支持自定义分类／标签、搜索／收藏、批量上传、追加附件和封面，也支持链接／分享文字收藏，但不自动读取网页。在单条剧本、专场和个人项目中点“选择参考文件夹”；单条与所属项目的文件夹合并、去重，旧版直接项目关联仍有效。文字说明、场地尺寸、服装库存与已选造型、最多4张有效本机图片进入生成请求。My·工作与 My·个人的审美卡、项目文件夹、场景和服装全部默认隔离；只有你主动点“复制到…”才生成另一空间的独立副本，之后互不影响。当前是单层文件夹，不支持嵌套。
9. 我的资料：My·工作与 My·个人分开填写身份、经历、目标，上传 TXT／MD／DOCX／PDF／图片。文本PDF先用 Poppler 提取；无文本层时尝试对前30页OCR，结果明确标注并必须人工核对。默认不发送AI，开启总开关并勾选文档后才使用其文字。
10. My·个人：自由创作人空间，管理导演／摄影／博主项目、自由选题和AI实验。My·工作：你当前的公司工作空间，保留内容总监的专场标准和AI创意补给。两个空间的项目、选题、资料、灵感、反推和审美记忆都不自动互通。My·工作首页的月度预算默认只按“约3项目／10条脚本／6条深化／¥800”估算，不限制实际数量；批量生成前会显示单次费用估算。
11. 灵感速记：My·工作／My·个人各有独立碎片库，首页顶部提供醒目的速记卡片，各工作页右下角固定“＋ 记灵感”，侧栏入口高亮；一键进入语音／文字记录区，未提交草稿可继续，不会自动启动麦克风。语音录制（最长10分钟）、导入录音、文字草稿自动保存、单条AI提炼、勾选2–8条组合、转为新选题；原始记录和提炼历史分开保存。录音存在浏览器IndexedDB，无需模型或上传服务器；完整ZIP备份会包含录音，清理网站数据前务必备份。

“AI创意补给”是My·工作的前置创意决策台：按任务类型、平台、目标、关联项目、观众、已核实事实和拍摄条件生成6个候选方向；每个方向提供一句话概念、核心画面、五维评分与评分依据。候选可标记为唯一主推、备选或淘汰，可调用AI继续深化为前三秒开场、故事推进、3个关键画面、汇报话术与最小可行拍摄方式，再转入选题库。生成会读取当前空间内已授权的工作资料、关联项目文字，以及最多8条收藏参考的说明和其中最多4张本机图片；不会自动读取只有链接的网页，也不会冒充实时热点监测。

旧版 `xuan_ti_ku_inspirations_<空间>` 记录按ID复制迁移、去重，原键不删除；旧录音仍引用原存储，完整ZIP导出时打包为独立音频。浏览器语音转写需单独勾选许可，可能向浏览器服务商发送音频；不是本地离线保证，也不是方舟的录音文件转写。识别失败保留录音、提示补文字；导入的音频尚不自动转写。AI只提炼已有文字，不假装听过未转写录音。真实语音识别质量需在实际浏览器和网络中测试。

视频反推不再把用户带去新建选题、场景参考、服装参考或生成媒体；当前任务就是一份能立即拿出来汇报的故事PDF。旧版 JSON 导入、旧迁移记录、旧版分析历史与单条 JSON 下载已移除；需要迁移或备份当前成果时统一使用“成果与备份”的完整 ZIP。

旧版共享审美库首次进入新版时会做一次保留式拆分：有历史项目关联的素材按项目空间归属；未关联项目的长期审美收藏默认归入 My·个人；若同一旧文件夹确实被两边项目使用，两个空间各建一份独立副本。旧存储键保留，不会因迁移删除。

每个素材可独立重做。重做图像把当前版本作为编辑参考；旧版不覆盖。视频排队任务 ID 会保存，暂停后可继续查询。停止不会取消上游已开始的付费任务。图片请求与 FFmpeg 当前任务仍会完成；后续批量生成停止。

## 日常审美积累与项目参考

“总审美库 · 全部资料”用于长期收藏喜欢的画面、摄影、美术、服装和其他参考，不要求先有项目。“项目参考文件夹”是从总库挑选的针对性集合，取消引用不删除原素材，同一素材可用于多个文件夹。

封面资料不再作为多个项目文件夹并排展示，而统一进入“封面参考”分类；分类内部按“过往封面、人物照片、纯字体、增量优化”子级筛选。历史封面继续作为账号风格锚点，增量优化必须对应具体视频内容。

在专场排期或单条剧本（含深化页）点“新建项目参考文件夹”，自定义名称，例如“双十一我冠是军”，填写本项目借鉴重点与不要照搬的部分，再按关键词、分类、收藏筛选总库，以缩略图勾选。筛选不会清掉已选项。保存后自动关联当前专场／单片并留在原工作台；以后点“挑选／调整参考”继续迭代。总库的“喜欢什么”备注不因项目说明变化而被覆盖。

单片继承所属项目的文件夹；修改共享文件夹会影响所有引用它的项目。只希望影响某一条片时，应为该片另外建立文件夹。收藏积累本身不是自动训练AI，生成仍使用当前明确关联的参考和现有资料权限。

### 从网站收藏参考

- 公网随身版支持接收浏览器/PWA分享参数，或在“链接”采集里从剪贴板粘贴网址；可同时上传一张截图或网站导出的 PDF。
- “我的”页提供“收藏到 JINHUA”书签按钮。电脑浏览器可把它拖进书签栏；浏览网页时点击，会带入页面标题、网址和当前选中文字。
- 网页收藏先进入随身收件箱，回到 Mac 后再确认分类、标签、使用范围和项目参考文件夹，默认进入审美库；也可改存为灵感文字。
- ShotDeck 等登录素材库只保存原始链接、你的说明和你主动上传的截图/导出文件，不自动登录、爬取或批量下载。建议标记为“仅内部视觉参考”。
- 审美卡的使用范围可标记为“待确认、只保存链接、仅内部视觉参考、本人／团队原创素材、已确认授权素材”。这些标签用于提醒，不替代真实授权文件。

## PPT 和数据在哪里

- PPT：浏览器默认下载目录（通常“下载”），以及同一浏览器的“成果与备份”。文件名来自脚本／专场标题。
- 文字、关联和版本：该浏览器的 localStorage，My·工作 / My·个人隔离；审美资料和项目参考文件夹也分空间存储。
- PPT 二进制：该浏览器的 IndexedDB。清除网站数据会移除本机成果索引与 PPT 缓存，请另存下载文件。
- 上传和生成媒体：项目目录 `.lance-data/media/`。不是临时外链，不会因上游签名链接过期而失效。
- ZIP 备份：当前空间 JSON、所引用的媒体、当前空间的审美素材和文件夹；已导出的 PPT 请另外下载保管。恢复以副本追加，文件夹与项目／素材的关联映射为新ID，不覆盖原稿。另一空间需切换过去单独导出。
- 旧版：仍读取旧存储键；新版首次打开会复制可识别的选题文字与专场关联，不删除旧数据。旧外链媒体不会冒充已核验新素材。

必须使用固定浏览器与固定地址（`localhost` 与 `127.0.0.1` 是不同存储空间）。**当前没有全量云同步，公网动态服务运行在 Render**。GitHub Pages 只能提供静态页面，不能执行本机生成、核验与视频合成。Render 公网根地址直接打开完整工作台；轻量随身版使用明确的 `/mobile.html` 地址，不再按设备自动跳转。模型密钥仍只保存在 Render 环境变量中，新的付费生成请求按来源做每小时基础限流。默认免费实例会休眠且服务器文件不持久；长期媒体保存和稳定视频处理需要以后升级为付费实例并挂载持久盘，详见 [部署说明](deployment/README.md)。

## 检查

```bash
npm ci
npm test
```

包括34项 JavaScript、9项 Python 测试：快速汇报三套封面验收、PPT 内嵌媒体、文件安全、上传核验、公开链接解析、12帧提取、实际25镜合成、旧库迁移、工作／个人审美库拆分、反推补充资料、资料提取、碎片提炼、文件夹关联／恢复、反推双用途、总库筛选与项目内新建和监听保护。`tests/report-browser.cjs`（三种导出、缺项、讨论稿标记、文件名与AI提炼保护）、`tests/browser.cjs`、`tests/reverse-browser.cjs`、`tests/library-profile-browser.cjs`、`tests/fragments-browser.cjs`、`tests/folders-browser.cjs` 可用 Playwright + 本机 Chrome 运行；使用隔离浏览器、人工合成素材和模拟麦克风，语音识别与AI返回均为明确模拟，不使用真实麦克风或付费AI。`test-output` 样片仅供软件测试，绝非AI创意成果。

真实生成尚待验收：一个单条完整案例、一场六条脚本、一条25镜深化片，以及 Lance 实际场地图和历史服装视频。详见 `使用报告与修改意见.md`。

## 安全

此前截图和历史代码出现过密钥。即使是测试账户，也请立即轮换 Ark Key、火山 AK/SK 和 Supabase secret/service-role key；不要等正式上线。新版不把这些密钥写入前端或提交 Git。不要把这个本地服务直接暴露公网。
