## 1. 重建/排障时先做四件事

```bash
# 1) 谁占着 80/443？
ss -lntp | grep -E ':(80|443)\s'

# 2) Docker 里有没有本项目？
docker ps -a --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'

# 3) 旧 Caddy 是不是 systemd 装的？
systemctl status caddy --no-pager 2>/dev/null | head -5

# 4) 域名到底解析到哪？
dig +short <域名> @8.8.8.8

# 5) 本机绕过 DNS 试探
curl -sI -H 'Host: <域名>' http://127.0.0.1/
```

对应处理：
- **A. 80/443 被 systemd 的 caddy 占着**（老尝试残留）→ `systemctl stop caddy && systemctl disable caddy`，再交给 compose 里的 Caddy。
- **B. docker 里有 `vps-caddy-1` / `vps-lance-1`** → `cd /opt/jinhua/deployment/vps && docker compose logs --tail=80 caddy` 看 ACME 报错。
- **C. `dig` 没返回 119.28.20.166** → 先改 DNS，再重启 Caddy（证书会自动重试）。

## 4. 服务器初始化（Ubuntu 22.04/24.04）

```bash
# 4.1 加 2G swap（2 核 2G 构建镜像时防 OOM）
fallocate -l 2G /swapfile && chmod 600 /swapfile && mkswap /swapfile && swapon /swapfile
grep -q '/swapfile' /etc/fstab || echo '/swapfile none swap sw 0 0' >> /etc/fstab
free -h

# 4.2 装 Docker（官方脚本，香港网络直连没问题）
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version && docker compose version

# 4.3 取代码（报价系统在 feature 分支；main 还没有 quote/）
apt-get update && apt-get install -y git
git clone -b feature/equipment-quote https://github.com/laijinghua624624-dotcom/JINHUA.git /opt/jinhua
cd /opt/jinhua && git log --oneline -1
```

> `main` 分支目前不含 `quote/`（差 20 个文件、约 4000 行）。确认稳定后再合并到 main 并用 main 部署。

## 5. 配置 `.env`（含模型密钥，权限 600）

```bash
cd /opt/jinhua/deployment/vps

# 5.1 从本机传密钥（本机执行）
scp -i ~/.ssh/tencent_hk_ed25519 \
  "/Users/lancelai/Documents/ChatGPT/个人/JINHUA/.env" \
  root@119.28.20.166:/opt/jinhua/deployment/vps/.env

# 5.2 服务器上追加站点变量（域名替换成你的真实域名）
cat >> .env <<'EOF'
SITE_ADDR=<域名>
PUBLIC_URL=https://<域名>
ALLOWED_HOSTS=<域名>
EOF
chmod 600 .env
```

要点：
- `SITE_ADDR` 只写域名，**不要带 `https://`**；`PUBLIC_URL` 才带 `https://`，且不要结尾斜杠。
- `ALLOWED_HOSTS` 与域名一致（`studio_server.py` 里 Host 校验会用它，否则全站 403）。

## 10. 已知限制（先接受，别当 bug）

- **本机历史数据不自动上云**：本机 `.lance-data` 约 3.1 GB（媒体）。要迁移需单独 `scp -r` 到服务器 `/data` 再改属主；浏览器里的项目/关联数据本来就在浏览器侧，换网址后要重新导入（先在旧网址导出 ZIP）。
- **手机打卡/报销上传（Node 8137）未并入**：`quote/` 里的上传服务还是独立 Node 服务，云上要外网手机上传得另加 Caddy 路由。
- **2 核 2G**：25 镜 FFmpeg 合成会慢；视频生成是调 API 不占 CPU。建议至少挂 2G swap（上面已做）。
- **香港机房**：大陆访问无备案要求，但跨境延迟比本机高；国内模型 API（DeepSeek/火山）正常。
