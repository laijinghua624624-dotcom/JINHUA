# 出发点引擎 · studio-origin.js

> 先立住“为什么做这件事”，再谈创意。质量不是从六个候选里挑出来的，是从一个张力里挖出来的。

## 为什么要它

现在系统里的「AI 创意补给」是**广度机器**：一次给 6 个候选 + 五维评分。它治不了两个真实痛点：

| 痛点 | 原因 | 这个引擎怎么治 |
|---|---|---|
| 想创意慢、质量不高 | 每次从零开始；生成时没读关键素材（上次批了什么、否了什么、场地多大、参考片的哪个机制） | 素材先入库并编号，创意必须从素材里长出来；**只给 1 个主张** |
| 包装汇报逻辑混乱 | 产出的是平铺字段，没有因果约束 | 强制「张力 → 主张 → 反方 → 退路 → 画面 → 代价」链条，每一环挂依据 |

配套的 10 页单条模板、14 页专场模板**不用改**：这个引擎的输出正好一格一格填进去。

## 输入：六类素材（每条自动编号 m1、m2…）

| 类型 | 说明 |
|---|---|
| `fact` 业务事实 | 谁要用、什么时候用、要达成什么。**硬门槛**，缺了不允许谈出发点 |
| `insight` 观众洞察 | 这群人此刻在意什么、犹豫什么；必须说得出根据 |
| `mechanism` 参考机制 | 从反推库借哪条片子的哪个机制；只说机制，不搬情节 |
| `venue` 场地条件 | 大概尺寸、进光、可用空间、电源。**只有约数也可以**；缺了则必须写“假设风险” |
| `constraint` 资源限制 | 天数、人数、预算档、授权状态 |
| `history` 历史结果 | 上次批了什么、否了什么、原因是什么。**最容易被忽略、也最值钱** |

## 输出：一个创意单元

```
张力（两侧都成立且冲突，必须引用素材编号）
主张（≤30 字，含具体画面，禁止空话词）
  ├ propositionBasis 依据
  ├ 反方 ×2（质疑 + 回应）
  └ 退路（砍到什么程度还成立）
关键画面 ×3（场地／机位／光／人／道具／秒数 —— 必须能指导拍摄）
代价（天数／人数／预算档／授权）
假设风险（假设不成立时的代价）
沉淀卡（机制／条件／批否原因／可复用画面）
```

## 质量闸门（不满足就不许进入汇报）

1. 缺业务事实 → 直接阻断
2. 缺场地 → 不阻断，但**必须**写清假设与代价（不许用“待核对”了事）
3. 张力两侧都要写清，且至少引用一条素材
4. 主张**只能有一个**，≤30 字，且不含空话词（赋能／打造／沉浸式／引爆／破圈／有温度／走心／极致／治愈／刷屏／矩阵／闭环／抓手／玩法／燃爆／全网最）
5. 主张必须有依据
6. 反方**至少两条**，每条都要有回应（一条等于没想过）
7. 必须有退路
8. 关键画面**恰好 3 个**，每个字段齐全；道具必须是数组
9. 必须有成本（未知写“待确认”，不许编数字）
10. 不合格结果**不覆盖**已有内容

判定：`readiness()` 返回 `可汇报` / `讨论稿 · 含待确认假设` / `缺项未完成`。

## 映射到现有 10 页单条模板

| 页 | 模板 | 取自 |
|---|---|---|
| 1 | 封面钩子 | 主张 + 片名 |
| 2 | 一页摘要 | 张力 + 主张 + 为什么成立 + 代价一行 |
| 3 | 故事结构 | 退路 + 反方的问题 |
| 4 | 完整脚本 | 备注（画面与台词同页） |
| 5 | 影像与摄影 | **3 个关键画面**（场地／机位／光／人／道具／秒数） |
| 6 | 视频封面推荐 | 交给封面模块 |
| 7 | 视觉参考 | 每个画面“支撑什么”（引用依据编号） |
| 8 | AI 视频参考 | 开场／中间／结尾 = 画面 1/2/3 |
| 9 | 首选方向 | 主张 + 对反方的回应 |
| 10 | 深入优化 | 退路 + 假设风险 |

## 最小接入（一次文字调用）

```js
const O=StudioOrigin, u=O.create(title,'单条');
O.addMaterial(u,'fact',facts,'需求会');
O.addMaterial(u,'venue','约 4×6 米，一扇朝东窗','勘景记录（约数）');
O.addMaterial(u,'history','上次被否：太文艺','10月纪要');
const {text}=await api('chat',{purpose:'director',prompt:O.prompt(u),references:[]});
O.accept(u,JSON.parse(text));          // 不合格会 throw，且不覆盖已有内容
const blocks=O.toPitchBlocks(u);       // 直接喂给现有 PPT 模板
const card=O.sediment(u,'rejected','和专场关系不清');   // 沉淀，供下次复用
```

