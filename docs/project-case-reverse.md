# 按项目整理历史视频案例

入口：参考库 → 整场项目反推。

1. 填项目名称，批量选择视频文件。无需先建立执行项目或规划十条脚本。
2. 上传仅归档视频并提取真实封面，不调用AI。单次最多30个文件，每个案例最多60条视频／时间段。
3. 点击“生成整体案例”，确认本次轻量识图数量与费用提示。成功的单条概览会即时保存；停止或失败后可以继续，不重复分析未变化的成功条目。
4. 预览主题、分工、视觉定调、复用方法与待核对事项，可直接导出整体PPT/PDF，不强制逐条深拆。
5. 需要详细分析时，再点对应视频的“深入反推这条”，提取12帧后启动原有反推流程。

## 边界

- 长录像超过10分钟会按时间段归档，共用原文件；每段概览先采样3帧，深拆采样12帧。不是自动切镜，也不表示完整观看了视频或分析了声音。
- 长录像时间段不支持单独音轨转写，防止将整片台词误用于本段。可填写已核对的台词。
- 上传顺序不等于发布顺序，作者意图、商业效果、预算等必须核对。部分视频失败时，导出会明确覆盖范围。
- 支持多选文件，不解包ZIP。材料仍遵循现有工作台的保存、备份和云同步机制；离开页面或关闭电脑不会继续执行浏览器中的队列。
- “移出项目”保留素材和分析，在项目底部可以恢复。不会删除电脑里的原视频。
- PDF需要服务端安装 `requirements.txt`；GitHub Pages只有静态页面，须连接完整服务。

## 开发验证

`npm test` 执行回归。可用已安装ReportLab的Python运行 `tests/serve_reverse_case.py`，在独立8793端口测试。它使用临时媒体目录、禁用云配置，AI响应为明确标记的模拟结果；不加载服务端密钥，不访问真实AI。
