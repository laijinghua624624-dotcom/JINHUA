# JINHUA 系统真实测评与模型 / Skills 建议

日期：2026-09-16  
测试任务：3 小时内完成“初瑞雪 9 月 28 日中秋专场”首轮汇报；内容为 4 条预热、2 条自述、1 条祝福，共 7 条。

## 一句话结论

JINHUA 已经是一个**有严格交付标准的个人创意工作台**，但还不是一个真正能处理临时需求的“内容总监系统”。它现在最强的是素材归档、完成度校验和 PPT 导出；最弱的是模糊需求判断、数量变化、阶段性汇报、生成排队与真实模型接入。

综合评分：**6.2 / 10**。

- 作为个人原型：7.5 / 10
- 作为 3 小时应急提案系统：4 / 10
- 作为可稳定生产的 AI 内容系统：3 / 10（当前未配置真实模型）

## 实测证据

- 自动测试：28 个 JavaScript 测试 + 8 个 Python 测试全部通过。
- 文件与完成度：能严格阻止“用提示词冒充图片”“用普通视频冒充 8 秒 AI 参考”，这是优点。
- PPT：能导出可编辑文字、内嵌图像与原生视频的真实 PPT，不是网页截图。
- 当前服务：`keyConfigured=false`，文本、图片、视频模型 ID 全为空，所以真实生成链路尚未跑通。
- 专场数量：代码与测试都写死为“恰好 6 条”。本次真实任务是 7 条，系统无法自然承接。
- 当前“完整快速汇报”若按 7 条计算，需要 21–35 张视觉参考图、21 段 8 秒视频（共 168 秒 AI 视频）。这不应该成为 3 小时方向会版本的前置门槛。

## 必须先改的 6 件事

1. **立即轮换所有曾在截图、说明页或 GitHub 出现的 Key。** 特别是 Supabase `service_role`，绝不能进入前端、GitHub Pages 或教程页面。浏览器只允许使用公开 anon / publishable key，敏感调用必须走后端。
2. **专场条数改成 1–12 可配置。** 默认可以是 6，但不能“恰好 6”。项目应保存 `scriptTarget`，完成度按实际条数计算。
3. **把交付拆成三层。** A：30–180 分钟方向会版；B：批准后的快速完整汇报（每条 3–5 图 + 3 段 8 秒）；C：深入制作版（25 镜、单镜修改、完整成片参考）。
4. **增加“需求空白与老板决策”页面。** 每次先输出已知、未知、假设、风险和必须拍板项，禁止 AI 把未知内容补成事实。
5. **增加日期与发布节奏校验。** 本次 9 月 28 日直播晚于 9 月 25–27 日中秋假期，系统应主动提醒“节后专场”，而不是继续套用“中秋当天”文案。
6. **生成任务改成队列。** 显示预计张数、视频秒数、成本、状态、失败原因、重试与降级交付；单个生成失败不能卡死整份汇报。

## 推荐的最小模型组合

先不要接十几个模型。最稳的第一版是“1 个内容主模型 + 1 个图片模型 + 1 个视频模型 + 1 个语音识别 + 1 个向量模型”。

### 豆包 / 火山方舟主栈（最适合当前代码）

- 内容总监与复杂策划：**Doubao-Seed-2.1-pro**。用于模糊需求拆解、母题、7 条内容矩阵、脚本与最终审片。
- 高频提炼与批处理：**Doubao-Seed-2.1-turbo**。用于灵感整理、标签、摘要、素材描述；不要让 Pro 做所有小任务。
- 视觉参考：**Doubao-Seedream-5.0-lite** 用于快速方向图；**Seedream-4.5** 用于更稳定的最终参考与一致性尝试。
- 三段 8 秒动态参考：**Doubao-Seedance-2.0-fast** 先做方向预演；通过后再用 **Seedance-2.0** 做重点镜头。
- 语音灵感与采访：**豆包录音文件识别 2.0 / ASR**，支持把语音、视频采访转成可编辑文本。
- 审美库检索：**Doubao-embedding-vision**，让系统按画面、摄影、场景、服装与语言共同找参考，而不是只靠文件夹名称。

## 最值得做的 5 个自定义 Skill

Skill 不是“再装一个模型”，而是把 Lance 的判断标准固化成工作流程。

1. **Lance·快速接需求**：把一句话需求转成已知 / 未知 / 假设 / 决策题 / 交付层级 / 时间预算。
2. **Lance·专场架构**：根据任意条数生成内容矩阵，明确每条片的任务、受众、发布日、CTA 与差异化。
3. **Lance·创意审片**：检查俗套、同质化、假信息、情绪勒索、前 8 秒无钩子、商业硬拐和不可拍点。
4. **Lance·拍摄落地**：把概念转成场地、尺寸、机位、镜头、灯光、美术、服装、演员、时间、预算与风险清单。
5. **Lance·汇报导演**：按“方向会版 / 快速完整版 / 深化版”自动生成不同密度的可编辑 PPT，并明确缺失资产。

建议先把前 3 个合并成一个 `Lance内容总监` Skill；拍摄落地与汇报导演作为两个独立 Skill。现成的 presentations、documents、imagegen 能负责文件和视觉产出，但不能替代你的内容判断标准。

## 本次中秋压力测试给出的产品结论

系统不应该一接需求就问“21 段视频生成完了吗”，而应该先问：

1. 直播为什么在中秋假期之后？
2. 初瑞雪愿意公开讲到什么程度？
3. 七条内容各自承担什么任务？
4. 三小时内老板真正需要决定什么？

当这四个问题解决后，再进入图片、视频和 25 镜深化，才是内容总监工作流。
