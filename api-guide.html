🤖 豆包API 必需

用于AI智能体团队（想法策划/参考搜索/库管助手），支持文字对话、附件上传、创意生成。你已有API Key。

📋 配置字段

https://ark.cn-beijing.volces.com/api/v3
火山引擎方舟平台的API端点，固定不变
你的API Key（在火山引擎控制台获取）
以"AKLT"开头的字符串，注意保密不要泄露
如 doubao-1-5-pro-32k 或 ep-xxxxxxxx
可以是模型名称，也可以是你创建的接入点ID（推荐用接入点）

🔑 获取步骤

注册/登录火山引擎

访问 https://www.volcengine.com/，注册账号并完成实名认证。

开通方舟（Ark）服务

在控制台搜索"方舟"或"机器学习平台"，开通大模型服务。

创建API Key

进入方舟控制台 → API Key管理 → 创建新的API Key，复制保存。

创建模型接入点（推荐）

进入"在线推理" → "创建接入点" → 选择模型（如doubao-1.5-pro-32k）→ 获取接入点ID（ep-开头）。

在系统中配置

打开Lance智能裤 → 点击右上角设置图标 → 填入API Base URL、API Key、模型/接入点ID → 保存。

💡 小贴士：你已经有火山引擎账号（即梦API也是同一个平台），可以直接在同一个控制台获取豆包API Key，无需重复注册。

🎬 即梦API（AI视频生成） 需本地配置

用于审美参考库中的AI视频生成功能，支持文生视频和图生视频。凭据通过环境变量传给本地代理，不保存在代码库中。

📋 配置字段

http://localhost:8765
本地Python代理服务器地址，需要先运行代理脚本
在火山引擎控制台获取，通过 VOLC_ACCESS_KEY_ID 传入
请勿写入HTML、Python脚本、文档或Git提交
在火山引擎控制台获取，通过 VOLC_SECRET_ACCESS_KEY 传入
不要与任何人分享，发现泄露后应立即轮换

🚀 使用步骤

启动本地代理服务器

进入仓库目录，先设置两个凭据环境变量，再运行 python3 jimeng_proxy.py。完整命令见下方“本地代理服务器配置”。

确认代理运行

看到"代理服务器已启动，端口: 8765"表示成功，保持终端窗口打开。

在系统中生成视频

打开审美参考库 → 点击"AI生成视频" → 输入画面描述 → 选择时长和比例 → 提交生成。

等待生成完成

5秒视频约需1-2分钟，生成完成后自动保存到审美参考库。

⚠️ 注意：即梦API不能直接在浏览器中调用（有CORS限制），必须通过本地代理服务器转发。关闭终端窗口后代理会停止，需要重新启动。

🎯 支持的模型

文生视频：jimeng_t2v_v30（720P）
图生视频：jimeng_i2v_first_v30（首帧图生视频）
Pro版：jimeng_ti2v_v30_pro（更高质量）

视频规格：
- 时长：5秒 / 10秒
- 比例：9:16（竖屏）/ 16:9（横屏）/ 1:1（方形）
- 分辨率：720P

☁️ Supabase（云端数据同步） 可选

用于多设备数据自动同步，启用后iPhone/iPad/Mac打开同一个网址即可看到相同数据。免费注册即可使用。

📋 配置字段

https://xxxx.supabase.co
创建项目后在项目设置中获取
sb_publishable_...
只使用publishable key（或旧版anon public key）；绝不要使用service_role secret key

🔑 获取步骤

注册Supabase账号

访问 https://supabase.com/，用GitHub账号注册（免费）。

创建新项目

点击"New Project" → 填写项目名称 → 设置数据库密码 → 选择区域（推荐新加坡/东京，离中国近）→ 创建。

获取Project URL和publishable key

项目创建完成后 → 进入Project Settings → API → 复制Project URL和publishable key（旧项目可能显示anon public key）。不要复制service_role secret key。

创建数据表

进入SQL Editor → 执行以下SQL创建数据表：

-- 创建选题库表
CREATE TABLE topics (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  user_id TEXT,
  project TEXT,
  data JSONB,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- 创建审美参考库表
CREATE TABLE visuals (
  id UUID DEFAULT uuid_generate_v4() PRIMARY KEY,
  user_id TEXT,
  data JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

-- 启用行级安全
ALTER TABLE topics ENABLE ROW LEVEL SECURITY;
ALTER TABLE visuals ENABLE ROW LEVEL SECURITY;

-- 创建策略（允许所有操作，个人使用）
CREATE POLICY "Allow all" ON topics FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow all" ON visuals FOR ALL USING (true) WITH CHECK (true);

在系统中配置

打开Lance智能裤 → 设置 → 云端同步 → 填入Project URL和publishable key → 勾选"启用云端同步" → 保存。

💡 免费额度：Supabase免费版包含500MB数据库空间、1GB文件存储、每月5GB流量，个人使用完全足够。

❓ 常见问题

Q1：AI助手回复"API调用失败"怎么办？

A：首先检查API Key是否正确，然后检查网络连接。如果是公司网络，可能需要配置代理。也可以尝试更换模型/接入点ID。

Q2：即梦视频生成一直显示"生成中"怎么办？

A：5秒视频通常需要1-2分钟，10秒视频需要2-3分钟。如果超过5分钟还没完成，可能是代理服务器断开了，检查终端窗口是否还在运行。

Q3：Supabase同步后数据会覆盖本地吗？

A：系统采用"云端优先"策略，启用同步后会先从云端拉取数据，如果云端没有数据则上传本地数据。建议先在一台设备上配置好同步，确认数据上传成功后，再在其他设备上启用同步。

Q4：API Key安全吗？会上传到服务器吗？

A：豆包API Key默认保存在本地浏览器中；只有主动启用配置云同步时才会加密上传到你的Supabase。即梦AK/SK仅从本机环境变量读取，备份文件也不包含API密钥。

Q5：换电脑了怎么迁移数据？

A：有两种方式：① 使用"导出"功能把数据导出为JSON文件，在新电脑上"导入"；② 配置Supabase云端同步，新电脑上启用同步后自动拉取数据。

Q6：即梦API怎么计费？

A：即梦API按生成次数计费，具体价格参考火山引擎官网。新用户通常有免费额度，可以在控制台查看余额和用量。
